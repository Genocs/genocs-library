# Genocs.Persistence.EFCore.SqlServer

![Genocs Library Banner](https://raw.githubusercontent.com/Genocs/genocs-library/main/assets/genocs-library-banner.png)

Microsoft SQL Server database provider for Genocs EF Core persistence. Supports `net10.0`, `net9.0`, and `net8.0`.

## Installation

```bash
dotnet add package Genocs.Persistence.EFCore.SqlServer
```

## Getting Started

Register the provider alongside `AddEFCorePersistence` and set `DatabaseOptions:DBProvider` to `mssql`.

## Main Entry Points

- `AddSqlServerDbProvider`
