# Genocs.Persistence.EFCore.Oracle

![Genocs Library Banner](https://raw.githubusercontent.com/Genocs/genocs-library/main/assets/genocs-library-banner.png)

Oracle database provider for Genocs EF Core persistence. Supports `net10.0`, `net9.0`, and `net8.0`.

## Installation

```bash
dotnet add package Genocs.Persistence.EFCore.Oracle
```

## Getting Started

Register the provider alongside `AddEFCorePersistence` and set `DatabaseOptions:DBProvider` to `oracle`.

## Main Entry Points

- `AddOracleDbProvider`
